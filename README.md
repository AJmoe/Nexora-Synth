# Nexora Synth Website

A polished static website for Nexora Synth, built for easy hosting on GitHub Pages.

## What is included

- Responsive single-page layout
- Company profile content translated into a modern marketing site
- No build step required
- Ready to host from the repository root on GitHub Pages

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static server.

## GitHub Pages deployment

1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. In GitHub, open **Settings > Pages**.
4. Choose the branch that contains the site files and set the folder to `/root`.
5. Save and wait for the published URL.
